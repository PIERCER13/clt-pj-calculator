# Calculadora CLT Líquido vs. PJ | piercer

INSS + IRRF aproximados e quanto cobrar como PJ para igualar os benefícios CLT

## Funcionalidades

- **Seções principais**: Dados CLT, Dados PJ, Divisão do Bruto CLT
- **Ações disponíveis**: Resetar, PDF
- **Persistência automática**: salva alterações automaticamente no navegador (`localStorage`).
- **Multilíngue**: suporte integrado com botão de troca de idioma (`PT / EN / ES`).
- **Impressão / PDF**: layout otimizado em folha A4 via `@media print`.

## Como Executar

1. Execute `start.bat` para iniciar o servidor local na porta `8110`, ou abra `index.html` diretamente no navegador.
2. Acesse `http://localhost:8110`.
